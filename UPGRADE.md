# Доработка и доказательства готовности

Дата: 2026-10-09.

## Реализовано

Маскирование облаков/снега/теней по SCL, NDVI/NDMI, агрегация радарных каналов, отказ при плохом качестве данных. Запускаемый LogisticRegression baseline по признакам полей. Отложенные годы и полностью отдельные поля; тестовые поля исключаются также из ранних лет обучения. Матрица ошибок, macro-F1, balanced accuracy, безопасный JSON модели и проверка выхода за диапазон.

## Аналог и применённый подход

[TerraTorch](https://github.com/torchgeo/terratorch)

Контроль качества входных каналов и отдельный baseline перед внедрением foundation model. TerraTorch/Prithvi ещё не интегрированы: для них нужны реальные геоданные, разметка и лицензированные веса.

## Запуск и проверка

```bash
python ecoagri.py examples/synthetic_fields.json --test-year 2025 --out runs/demo
```

Регрессионные тесты: `python -m pytest -q`. Локальная среда проверки: Windows, Python 3.12. CI проверяет отдельную чистую среду.

## Что требуется для оценки 10/10

Провести отдельную пространственно-временную проверку на размеченных полях Казахстана. Измерить macro-F1 по культурам и регионам, ошибки на облачных сценах. NDMI не является диагнозом засухи, а классификатор не прогнозирует урожайность. Sentinel-1 и Sentinel-2 нужно заранее совместить по сетке; автоматической загрузки спутников пока нет.

Инженерные тесты подтверждают поведение кода; они не измеряют клиническую, гидрологическую или коммерческую точность. Метрики на синтетике нельзя переносить на реальные данные. Оценка 10/10 сейчас не заявляется.
