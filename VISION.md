## 📌 О проекте
**EcoAgri-Sentinel** — платформа мультимодального анализа спутниковых данных (оптика + радар) для сельского хозяйства Северного Казахстана. Используя геопространственные foundation-модели, она оценивает состояние посевов, прогнозирует урожайность зерновых, выявляет деградацию пастбищ и неиспользуемые сельхозземли.

## 🎯 Решаемая проблема
Северный Казахстан — основной зерновой регион страны, работающий в условиях рискованного земледелия: засухи, ветровая эрозия, короткий вегетационный период. Деградация пастбищ снижает продуктивность животноводства. Кроме того, часть сельхозземель числится используемыми, но фактически не обрабатывается. Объективный спутниковый мониторинг помогает фермерам, акиматам и контролирующим органам принимать решения на основе данных.

## 🧩 Задачи (downstream tasks)
| Задача | Тип | Ценность |
|---|---|---|
| Классификация культур (пшеница, ячмень, масличные, пар) | Сегментация | Структура посевов |
| Прогноз урожайности зерновых | Регрессия | Планирование, страхование |
| Мониторинг засухи и влажности почвы | Регрессия / индексы | Раннее предупреждение |
| Деградация пастбищ | Сегментация изменений | Устойчивое животноводство |
| Выявление неиспользуемых сельхозземель | Классификация временных рядов | Контроль целевого использования земель |
| Лесные пожары и состояние ленточных боров | Сегментация | Охрана лесного фонда |

## 🛠 Стек технологий
* **Экосистема:** Python 3.11+, PyTorch
* **Геопространственные библиотеки:** TorchGeo, TerraTorch (дообучение foundation-моделей), Rasterio, GDAL, xarray
* **Foundation-модели:** IBM/NASA **Prithvi-EO-2.0** (основная); для сравнения — TerraMind, Clay
* **Доступ к данным:** STAC API (`pystac-client`, `odc-stac`) через Copernicus Data Space Ecosystem и Microsoft Planetary Computer
* **Версионирование данных:** DVC
* **Визуализация:** Folium / Kepler.gl, GeoTIFF / Cloud-Optimized GeoTIFF

## 🛰 Данные
| Источник | Что даёт | Зачем |
|---|---|---|
| **Sentinel-2** (оптика, 10–20 м) | RGB, NIR, red-edge, SWIR | Вегетационные индексы, классификация культур |
| **Sentinel-1** (радар SAR) | Снимки в любую погоду | Работа при облачности, влажность почвы, структура посевов |
| **Landsat 8/9** | Длинная история (с 1980-х) | Многолетние тренды деградации |
| **ERA5 / метеоданные** | Осадки, температура | Признаки для прогноза урожайности |
| **Наземные данные** | Урожайность по районам и хозяйствам, полевые обследования | Обучение и проверка моделей |

> **Главный риск проекта — наземные данные.** Открытые датасеты (например, CropNet) собраны по США и для Казахстана не подходят напрямую. Нужны районная статистика урожайности Бюро национальной статистики и партнёрство с хозяйствами или аграрным университетом для полевой разметки.

## ⚙️ Архитектура
1. **Загрузка.** Поиск и скачивание сцен по STAC для заданного района и периода.
2. **Предобработка.** Маскирование облаков (SCL / s2cloudless), композиты по периодам, совмещение Sentinel-1 и Sentinel-2, нарезка на тайлы в TorchGeo.
3. **Извлечение признаков.** Prithvi-EO-2.0 (поддерживает временные ряды снимков).
4. **Дообучение** под конкретные задачи через TerraTorch.
5. **Оценка неопределённости.** Каждая карта сопровождается картой уверенности.
6. **Визуализация.** Геопривязанные маски (COG) на интерактивной карте, отчёты по районам.

## 📏 Метрики
| Задача | Метрика |
|---|---|
| Классификация культур | mIoU, F1 по классам |
| Урожайность | RMSE, MAPE на уровне района; проверка на отложенном году |
| Изменения пастбищ / неиспользуемые земли | Precision / Recall, проверка по выборке полевых точек |

Проверка всегда проводится на **годах, не участвовавших в обучении**: модель, которая видела засушливый год, легко «угадывает» его.

## 🚧 Ограничения
* Точность прогноза урожайности ограничена качеством наземных данных.
* Мелкие поля и межполосные лесополосы сложнее классифицировать при разрешении 10 м.
* Модель не заменяет полевую проверку: выявленные «неиспользуемые» участки — это сигнал для проверки, а не доказательство нарушения.
* Перенос модели на другие регионы требует дообучения.
